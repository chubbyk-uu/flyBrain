# 阶段6：需求与合并清洁的固定验收输入

日期：2026-09-13。状态：实施前已登记，阶段5提交后实施；本阶段门控已通过，见[结果报告](indoor-v2-stage-6-result.md)。
沿用[总修复计划](indoor-repair-plan-2026-09-13.md)的门槛，不以最终轨迹反向挑选输入。

## 状态与时间

- 饥饿：初值0.30，禁止食物接触，2 ms步进；60秒±一个窗口达到0.55。
  空中接近、无足部支撑、无MN9、无口器伸展、运动输出断连分别不能降低饥饿。
  native真正进食仍需Grounded、≥两足支持、body up-z>0.8及原有味觉/MN9/伸展门槛。
- 飞行疲劳：标准初值0.05、功率幅度0.85；分别水平速度60、0、0.5 mm/s，无支持，
  三者均增加并在30–45秒达到0.68。不把低水平速度解释为没有飞行耗能。
- 恢复：初值0.72、已锁定疲劳降落、Grounded、四足支持；静止及4 mm/s爬行各自
  在9–11秒恢复起飞资格。无支持下坠不恢复；不要求每次落地强制静止3.5秒。
- 所有需求状态有界；零dt/暂停不更新，reset恢复初态和随机序列。需要区分恢复起飞资格
  与实际起飞，不能用恢复阈值直接强行触发起飞。

## 清洁机会和动作

- 用独立、可重放的种子随机序列产生机会间隔；种子11/13/17/19/23。
  正式低冲动0.10开始，首次机会10–15秒；每次完成后下一机会10–20秒。
  各种子连续20个可执行机会，间隔均合规、不全相同；同种子严格重放。
- 安全支持、饱食且神经证据持续有效的fixture，机会出现后2秒内启动；高冲动初态同样验证。
  固定在阈值以下（禁止累积）的fixture不得触发。机会时间与实际动作启动时间分别记录。
- 完整合并动作2–3秒，包含先搓前足、后擦头/眼的阶段；四条中后足支持。
  实际MuJoCo身体测量前足互距与前足到头/眼最短距离，各自对应阶段出现<1.5 mm。
  地板与茶几各自测量；不能只检查关节目标值或`completed_bouts`计数。
- 完成后降低冲动，至少5秒冷却包含在10–20秒间隔内；长期飞行/饥饿不能积攒待办次数。
  饥饿、危险、支持丢失及自主神经门控断连中断不记完成，不给完整清洁收益。
- 手动/无脑动作fixture只验证姿态与支持，不算自主事件。实际CNS中的自主启动、完成和
  视频证据另行核对，最终300秒整体验收至少4/5种子出现自主合并清洁。

短程真实CNS补充固定输入：种子11，地板`[0,-70,2.1]`及茶几`[0,0,32.1]`，初始饥饿0.30、
冲动0.90，两食物关闭，运行12秒；不手动请求动作、不关闭正常起飞。连接组须实际自主完成，
清洁门控断连和运动输出断连各做配对。单独测搓足纯阶段phase 0.20–0.40与擦头阶段
0.52–0.85，防止用倒下/擦头时的偶然靠近冒充前面的搓足；另核对四条中后足的实际接触。

## 工程机制边界

需求变量、随机机会、支撑稳定器和合并动作模板都是工程层，不是声称连接组自行还原了
饥饿/疲劳/清洁动机。CNS感觉读出、运动输出和清洁神经证据必须对相应行为有因果参与。
保留dirt兼容字段时，面向用户统一显示“清洁冲动”；禁止据此声称模拟了真实积灰。
若增加可选的短暂静止恢复，它应是有需求/支持约束的可重放随机选择，而非每次强制同一
静止时长；爬行同样可以恢复疲劳。最终仍以物理轨迹检查重复和停滞，而不是只看状态标签。

代码核对补充：既有`BrainBodyBridge`不只是刺激清洁感觉组，还按冲动以20 Hz上限驱动
`aDN1/aDN2`命令组（感觉组上限5 Hz），再读取对应脉冲进行门控。本阶段保留这个映射，
因此“自主”指无手动触发的工程需求—CNS门控—物理动作闭环，不代表连接组自行产生了
生物性清洁动机。录像使用`cns-check --record-display`记录的真实身体姿态离线回放；
回放不驱动仿真、不制造自主事件，也不作为实时浏览器性能证据。
