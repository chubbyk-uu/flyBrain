# 阶段5预登记：近源寻食与脱困

日期：2026-09-13。状态：已按预登记门控完成；见[阶段5结果](indoor-v2-stage-5-result.md)。

权威任务定义为`assets/neuromechfly/scenes/indoor-v2-foraging-tasks.json`。四任务分别从
地板(96,-12,2.1)、茶几(-70,-4,32.1)、盆底(-61,12,32.1)、默认双源(26,-12,32.1)出生，
朝向180°、30°、0°、0°；每任务相同五种子11/13/17/19/23。单源任务关闭另一资源。
前两种跨高度任务允许初始三维距离超出15–35 mm建议范围；不得按失败结果挪近源。
每次从同一正式初态开始，无额外出生休息。先检查出生点没有刚体穿透或初始taste。

真实进食门控使用逐2 ms窗口：同一资源taste、Grounded、≥两足接触、身体up-z>0.8，
MN9滤波活动≥现有homeostasis阈值、口器伸展≥现有阈值、hunger确实下降，同时连续≥0.2秒。
每类至少4/5首次有效进食≤20秒；失败、终点、首次触碰与有效进食分别报告。

脱困检测先在不使用食物坐标的合成fixture冻结：3秒窗口、5 mm重复区域；同时看过去位置、
感觉变化和局部重复，不能用累计路程冒充进展。以首尾0.5秒的平均感觉量比较，改善需超过
0.25 ppm或5%中的较大者，避免神经采样噪声反复清空停滞计时。圆周、往返、原地阻挡
必须触发；持续真正接近不触发；有实际进食/清洁/疲劳恢复时豁免并记录原因。
首次恢复后5秒内须离开原5 mm邻域或取得新的感觉改善。控制可使用本体位置、局部感觉历史、
现有碰撞/距离代理，不能读取资源真实位置生成导航目标。

运动输出断连和嗅觉诱发输入断连采用相同初态/种子配对；记录脉冲、工程指令和轨迹。
仅显示CNS仍在计算，或给工程控制器一个恒真神经开关，不算感觉/神经因果参与验收。

配对数值判据在读取本轮消融输出之前登记：运动断连不得有效进食，出生稳定0.5秒后累计
本体位移不超过配对连接运行的10%；嗅觉诱发输入断连每类成功数至少下降2/5，同时配对
轨迹在公共采样时刻的位置RMS差异>5 mm。核对初态哈希和同一运行程序哈希；记录实际ORN
脉冲/译码输出及运动命令，不能把不同场景、初始饥饿或物理步长产生的差异归因于消融。

首个明确代码缺陷：旧`minimum_acquisition_height_mm=55`使桌面/地板闻到气味也不能开始
ORN引导，必须先飞到55 mm，之后又锁住获取气味时的高度。本阶段先降低高度获取门槛，
再引入有感觉反馈的垂直搜索与无进展恢复；不能将这个固定高度现象归咎于真实连接组。

## 开发诊断记录（不是最终验收）

- 降低获取高度门槛后，默认双源种子11在5.282秒满足真实进食；原先的三个跨高度任务仍失败。
- 主动高度采样及近源制动候选使地板→糖果种子11在8.088秒满足真实进食。
- 花缘接触不等于稳定着陆：候选曾在约13°俯仰时提前关闭飞行支撑并跌下花朵。当前修正
  要求姿态对齐、低角速度/垂直速度及局部支撑余量；通过8个本体周边向下距离探测移向足够
  宽的支撑区域。该工程稳定器不读取食物坐标，也不改变视觉像素/BrainBodyBridge输入映射。
- `footprint-guard-v5/table-to-nectar-11.json`有9.576秒起连续1.954秒进食、饥饿下降记录，
  但评分器误用legacy habitat将索引1标为banana，自动判失败。已定位资源表加载错误；
  旧文件保留，必须用修正评分器重新测量，不能直接把旧报告改成通过。
- 后续行为改变了飞行时间占比，70 mm/s候选出现巡航p95回归，常规速度进一步选用60 mm/s；
  仍在预先约定60–100范围内。最终阶段须重新检查速度，历史阶段4数据保持原版本含义。
- 采样结束必须先到达选定高度再平移；保留6 mm通用接近余量，不使用食物真实高度。
  向下采样以脚下表面+5 mm为飞行下限，不能要求身体进入茶几内部。盆底候选v8已在
  11.572秒实际进食，但其地板→糖果回归失败，故v8未通过、未提交；保留失败报告。
- 地面窄支撑面增加局部落差避让，使用本体周围5 mm半径的向下距离探测；只调整有CNS
  步态活动时的转向/平移比例，不注入步态活动、不读取资源坐标。其用途是避免着陆后被
  暂态嗅觉转向带出花缘，不能以该反射证明大脑已识别花朵。
- 修正新支撑探测的装饰过滤：逐段跳过糖果表面可能越过薄桌面顶面、错误命中桌板底面。
  固定失败位置`[54,-11.6,30.68]`的回归先失败（虚假修正量0.714 mm），改为直接与可
  碰撞支持几何求交后通过；不修改现有native obstacle/retina感觉路径。
- v11连接组20/20实际进食成功；v12仅新增逐2 ms恢复超时计数、完整ORN读出脉冲计数，
  用同一v12程序重跑连接/运动断连/嗅觉断连整组。因果试验可并行，墙钟耗时不能作为
  独占GPU性能结果；最终Windows正式viewer性能另做。
