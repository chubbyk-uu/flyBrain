# indoor-v2 阶段4：飞行、起降与翼显示

日期：2026-09-13。状态：阶段4专项门控通过；阶段5–7未通过、未完成。

## 修复及边界

- 茶几上的绝对高度原先立即满足起飞完成条件，绕过渐变。现在从实际起飞点计算高度，
  起飞状态至少0.35秒；高度目标最大变化45 mm/s。后台出生稳定阶段不提前起飞。
  CNS飞行激活到高度目标的工程标定使用0.75–0.95活动范围，保留当前激活调制而非历史最大值；
  不更改神经元参数，也不把该经验标定声称为生物学对应关系。
- 常规速度候选70 mm/s、食物接近约30 mm/s；保留CNS输出幅度调制。原来接近速度
  比例0.02只对应约5.6 mm/s，改为0.10（约28 mm/s，取决于神经激活）。
  避障之后仍统一限制矢量速度≤100 mm/s、矢量加速度≤250 mm/s²。
- 高处下降目标30 mm/s，近支撑面12 mm/s。零平移指令增加自身位置保持：位置误差
  增益4/s、每轴校正限30 mm/s，仍经过统一矢量速度/加速度限制。只用本体位置，不读食物坐标。
- 触地后0.6秒维持站立控制和支撑，再恢复步态渐变；这不是疲劳机制的强制休息。
  reset重建FlightRuntime，清除力积分、速度限制器、位置保持及物理翼状态。
- 显示从真实可见翼网格计算翼展方向，按身体纵轴调整展开，不再将局部yaw角冒充展开角。
  完整幅度时展开50–90°，地面折叠15°；左右仍受神经/混合控制的转向信号调制。
  物理218 Hz翼载波不变，显示使用18 Hz符号化载波，不宣称60 Hz屏幕能还原每个真实翼拍。
  HUD将误导性的“Hz neural”改为“Hz physical command”，地面物理指令显示0 Hz。
- 未改MaleCNS pack、神经参数、BrainBodyBridge、神经身份映射、retina输入路径、身体DOF。
  工程飞行/接近控制确有上述修改，不宣称行为参数未改变。

## 已记录的失败与修正

- 90 mm/s候选的五种子20秒测试：种子23实际巡航速度p95=133.971 mm/s，超过120；
  其他种子不能代替它通过。随后常规指令降为70，全部种子重新测量。
- 固定地板/茶几各五次物理起降，茶几第5次曾从y=29.19继续前滑至40.76，落到地板。
  初始位置和朝向未移动；增加本体位置保持后，原用例回到桌面y约30处稳定触地。
- 落地后立即步行会使连续支撑判据中断，故增加真实0.6秒站立交接，不冻结/重写身体姿态。
- 物理测试区分飞行俯仰和支撑翻倒：飞行存在约47°目标俯仰，不能拿up-z≥0.7作为全过程
  “不翻倒”定义；分别检查空中up-z>0.3、最终支撑up-z>0.8、持续≥三足支撑0.5秒及无warning。
  早期失败记录未包装成通过；最终轨迹仍需与视频和完整CNS证据分别核对。

## 翼网格与实际画面

`tools/capture_wing_review.mjs`受控显示fixture使用native真实身体网格和姿态，但控制显示相位，
不注入神经/运动输入，也不作为自主起飞证据。俯视/侧视各48帧、慢放视频与测量保存在
`outputs/indoor-v2/stage-4/wing-review/`：实际网格两侧峰值均90°，翼根误差<1e-6 mm。
已亲自查看两视角峰值截图；胸翼连接连续、无穿胸，单帧只有当前两翼，不累积残影。

另用`--live`读取完整CNS实际流，既不覆盖翼信号也不覆盖姿态，记录位于
`outputs/indoor-v2/stage-4/live-wing-review/`。俯视native t=14.740–19.524秒，左/右最大
展开89.9998°/85.2781°；侧视t=19.630–23.530秒，89.9903°/88.9354°，均为Cruise。
已亲自查看俯视12/36帧和侧视12帧，核对真实飞行的展开、左右调制、翼根及近墙片段。
视频是逐帧12 FPS编码的审查素材，采样时间保留在JSON中，不冒充实时录屏或Windows性能证据。
该实际流来自90 mm/s候选，显示代码与70 mm/s候选相同；速度验收另用最终候选重新运行。
