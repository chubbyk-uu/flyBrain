## 范围和预定义检查

保留 CUDA MaleCNS pack、神经0.1 ms、MuJoCo 0.2 ms、完整身体、BrainBodyBridge 和当前感觉/神经门控路径。以下均为工程环境或动作参数，不宣称新的生物机制。

| 修改 | 目标与检查 |
| --- | --- |
| 顶部灯光 | 室内顶部增加向下灯与可见灯具；浏览器保留阴影，新增一张2048²聚光阴影图。亲自查看全景、桌面和果蝇近景，实测60 FPS上限下渲染表现，不把亮度提高等同于阴影合格。native灯同位置，retina路径不迁移。 |
| 起飞 | 升力启动斜坡0.35→0.55秒，高度命令最大变化45→35 mm/s；不改变降落速率。验证实际身体起飞稳定，无瞬间抬升/瞬移。巡航高度跟踪也受新的35 mm/s上限约束。 |
| 飞行疲劳 | 支撑恢复0.06→0.08/s，最少支撑10→7秒；0.72疲劳起点在静止/爬行fixture均约7秒恢复资格。悬停仍累积，飞行累积率不变。 |
| 糖 | 厚度1.2→0.4 mm，底面贴桌面z=30，中心z=30.2；气味/味觉同权威坐标。实际进食录像中口器不被厚糖遮住。 |
| 饥饿 | 未进食增长率0.0041667→0.005/s；从0.30到0.55约50秒，误差≤一个2 ms控制窗，进食下降率不变。 |
| 清洁 | 合并动作2.5→4秒；只在互搓段插入1.5秒，保持原抬脚/承重/擦头/落脚时序，完整互搓姿态约1.925秒；互搓两前脚反向运动，关节2/6幅度0.12/0.20 rad，擦头仍为原0.04/0.04 rad。保留四足支撑、安全中止和神经门控。实际native关节录像核验，不以状态文字替代动作。 |

## 结果

旧阶段7并未完成，不能引用旧截图作为新版验收。

实施中纠正：直接按比例拉长整个清洁动作曾令桌面承重中止，现只延长中间互搓段；前后承重时序不变。第一版0.2 mm花瓣的table-to-nectar任务20秒未进食，真实口器距花芯最近仍约4.37 mm，不是味觉已接触却不计分。只压薄花瓣至0.02 mm后同出生点在7.506秒验证进食，不扩大味觉范围或移动出生点。随后亲自看花芯侧面，进一步压薄花芯并同步资源中心；最终布局的结果另外记录，失败和中间候选均保留。
