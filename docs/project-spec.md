# 项目目标与实施规范

更新：2026-09-13。当前范围依据；用户后续决定优先。历史报告保留当时配置、失败及测量，
不作为当前待办清单。运行见[README](../README.md)，资料见[文档索引](README.md)。

## 总体目标与当前路线

保留同一标本 MaleCNS v1.0 brain + VNC，制作能感知环境、受神经活动调节并在物理世界中
活动的混合驱动果蝇。允许工程规则管理需求、协调动作与避障，不要求全部行为从连接组自行
涌现，也不能把神经网络变成无作用的后台计算。

当前采用 Rust/CUDA + 原生 MuJoCo + Windows Three.js viewer。神经 0.1 ms、物理
0.2 ms、脑体交换 500 Hz；WebSocket 发布 20–30 Hz 姿态，浏览器独立插值并默认限制
60 FPS。native retina 仍负责感觉采样，网页复眼和神经图仅显示。停止以 WSLg classic
OpenGL 主 viewer 为优化目标；身体/气动力简化及浏览器异步 retina 均为后备，未启用。

保留原 Metal/WebGPU 基线、完整身体、BrainBodyBridge 与当前 sensory/motor 路径；
后续改变感觉或行为须单独记录及验证，不能与神经后端等价优化混在一起。

## 数据及科学边界

- pack：166,700 神经元、24,469,412 有符号有向边、120,260,398 解剖接触。
  保留身份/顺序、CSR、权重、I/O 绑定及来源哈希；不跨标本拼接、虚构连接。
- 沿用原导入器筛选及递质支持规则，不是原始分割表的所有节点/出边。新克隆须恢复
  `outputs/packs/male_cns_v1` 并校验，不能重建 I/O 来掩盖哈希不符。
- LIF 模型不是完整动物复制，不恢复供体记忆、身份、学习或完整生理状态。
- 嗅觉、味觉及运动读出有工程映射；视觉代理不等于识别糖、花或恢复完整视觉通路。
  见 [embodiment](cns-embodiment.md)、[odor guidance](cns-odor-guidance.md)、
  [pathway assay](male-cns-pathway.md)。
- 神经图使用真实总放电率与累计参与统计，不宣称思想解码、同时活跃数或真实 EEG。
  视频“活过来了”属于创作表达，不是生命或意识的科学验收结论。

## 场景与混合行为

当前 `indoor-v2` 是独立重建的小室内世界：低矮长茶几、桌上薄糖液与平放花朵，
无盆/茎/叶、地垫及墙外旧装饰。顶部主光配少量环境光，保留降低配置的阴影。
无环境风，两源使用同一食物气味并叠加三维浓度；不向寻食控制器提供目标坐标。
食物挥发刺激是工程设定，不宣称纯蔗糖本身散发这种气味。

目标包括探索、爬行、平缓起飞、自由飞行、落地、糖液/花蜜实际进食、前腿互搓后擦头眼。
升降和脱困不应瞬移；允许工程安全控制，但不能固定播放动作列表伪装自主行为。

默认值以 `rust/src/homeostasis.rs`、`rust/src/grooming.rs` 为准：

| 状态 | 当前语义/默认值 |
| --- | --- |
| 饥饿 | 初始 0.72；未进食 +0.005/s；0.55 开始饥饿、0.30 解除；从 0.30 到 0.55 约 50 仿真秒（取代旧 60 秒） |
| 进食 | 物理味觉接触、口器伸展及 MN9 门控成立才减饥饿，不因接近资源或状态标签直接计分 |
| 飞行疲劳 | 初始 0.05；有功飞行含悬停按 `0.016 × effort/s` 累积，effort 随翼幅变化；0.68 请求降落 |
| 支撑恢复 | 着地爬行或静止均可 -0.08/s；≤0.25 且有效着地至少 7 秒才解除疲劳起飞禁令；不是所有初态固定 7 秒 |
| 清洁冲动 | 一个习惯性倾向变量，不代表脏污；可复现随机间隔，饥饿/支撑/神经门控决定是否执行 |
| 合并清洁 | 4 秒一套，约 1.5 秒前伸并拢互搓，再擦头/眼；至少四足支撑并保留中断保护 |

神经活动参与感觉响应、运动和取食门控；需求仲裁、步态、翼波形、姿态稳定和清洁轨迹
由工程控制器执行。清洁因果对照见[前腿修正](forward-rub-2026-09-13.md)，不能将候选
回路或工程轨迹说成已经恢复真实果蝇完整清洁回路。

## 网页生命周期

后台启动即运行；每个后台进程仅首次正式网页场景就绪时完整重置一次并继续。
刷新、重连、多标签不重复自动重置。手动重置更换行为种子并暂停，用户可继续；
实验通过显式种子复现，不以随机重置作为确定性测试。网页显示需求、仿真倍率、FPS、
native 双眼与神经活动；不得将显示 FPS 当仿真速度。

## 验收及未完成项

1. 神经后端：同设备/构建/固定输入自身确定性；tiny fixture、spike、delay ring、
   refractory、严格阈值、稠密/稀疏、跨窗口执行顺序正确；报告首次数值或 spike 分歧。
   完整 CNS 比较 population response、关键群体及既有因果门控，不要求长期 CPU-f64 逐神经元一致。
2. 行为：短程实际进食、起降、支撑与清洁正/负对照；版本、种子、参数及资源哈希明确。
   保留 MeVP24–DNp10 假说及严格长期 f64 状态门槛的历史失败，不改口为通过。
3. 长程目标：5 个固定种子各 300 仿真秒，覆盖两个源的实际进食、爬行/飞行、支撑恢复、
   清洁，无机械循环或长期无进展。旧阶段 7 未通过整体验收；后续用户选择更简单桌面布局
   并接受演示，不等于五种子门控已补齐。最终布局仍需独立重跑长程门控。
4. 视觉/性能：全景、侧面、食物/清洁近景必须实际检查；native 实时倍率和 browser FPS
   独立实测。短测约 60 FPS 不代表所有负载或长期 ≥1×；视频回放不算实时验收。
5. 自主翻身/振翅自救、完整视觉通路、浏览器感觉 readback 暂缓。

已完成的 CUDA、原生接入、时间步、viewer 和室内结果见[索引](README.md)。
[旧修复计划](indoor-repair-plan-2026-09-13.md)保留阶段门槛/历史记录，旧盆栽、

## 开发规则

只使用独立 `flybrain` Conda 环境，下载沿用环境代理，不改共享环境或提交代理凭据。
一阶段一组可解释改动，通过预先约定门控再汇报/提交；不得事后降低失败门槛。
改感觉/动作需因果和身体证据；纯显示/视频/文档改动只运行相关检查，不声称全库长测重跑。
实验报告保留日期、版本、输入哈希及通过/失败/未执行；当前指南不重复堆积历史进度。
